# Phase 5 実装計画(管理機能)

利用者の指示(2026-10-10「このまま進めてください」)を承認として扱う。§9 の順番どおりに追加する。

## 1. タスクバックログ
- プロジェクトごとのタスク一覧(未着手 / 進行中 / 完了)。追加・編集・削除・並べ替え
- 「セッションで開始」: プロジェクトのピン留めプロファイルで新しいセッションを開き、タスクの内容を最初の指示として入力・送信する。タスクは「進行中」になり、セッションとつながる
- 右パネルの「タスク」タブ

## 2. Git 連携
- 右パネルの「差分」タブ: 表示中のセッションの作業フォルダについて、ブランチ、変更ファイル(追加/削除行数)、ファイルごとの差分(色付き)
- **コミット前のレビュー**: 差分を見てからコミット。コミットは確認ダイアログのあと `git add -A` → `git commit -m`
- **AI コミットメッセージ生成**: 「Claude Code に考えてもらう」で、表示中のセッションに依頼文を入力・送信する(Claude Code に依頼する、§5)。返ってきた文面は利用者がコピーして使う
- ペインの見出しにブランチ名を表示
- git はコマンドで呼び出し(`git status --porcelain=v2`、`git diff --numstat` など)、出力は読むだけ

## 3. プロンプトライブラリ
- よく使う指示を保存。`{{名前}}` / `{{名前:既定値}}` の変数と、組み込み変数 `{{project}}` `{{cwd}}` `{{branch}}` `{{profile}}`
- コマンドパレット(「プロンプト: …」)から選ぶ → 変数を入力 → 表示中のセッションの入力欄に貼り付け(送信はしない)
- **`/` で呼び出す**: プロンプトごとに「Claude Code のコマンドにする」を選べる。オンにすると、各プロファイルの設定フォルダの `commands/codedeck/<名前>.md` に書き出し、claude の中で `/<名前>` として使える(Claude Code の公式のカスタムコマンド機能。CLI の入力を書き換えずに `/` で呼び出せる)。CodeDeck が書くのは `commands/codedeck/` の中だけ
- JSON でエクスポート / インポート(§8)

## 4. スキル / MCP の管理画面
- プロファイルごとに、設定済みの MCP サーバー(`claude mcp list` の結果)とスキル(設定フォルダの `skills/` と、プロジェクトの `.claude/skills/`)を一覧する
- スキルの有効化 / 無効化: CodeDeck は `skills/<名前>` と `skills-disabled/<名前>` の間でフォルダを移動するだけ(元に戻せる)
- MCP の有効化 / 無効化や認証は、Claude Code 自身の `/mcp` 画面で行う(「このプロファイルで /mcp を開く」ボタンで、セッションに `/mcp` を入力)。CodeDeck は MCP の設定ファイルを直接書き換えない
- 資格情報(`.credentials.json`)や `.claude.json` は読まない

## 5. 統計
- プロジェクト別・プロファイル別の使用量(トークン)、セッション数、作業時間(フックの「作業中」から「完了」までの合計)
- 期間: 7日 / 30日。日ごとの使用量のグラフ
- 使用量の記録は Phase 3 と同じく、会話の記録のトークン数と時刻だけを読む(本文は読まない)。会話の ID からセッションとプロジェクトを特定する

## データ(SQLite v5)
- `tasks(id, project_id, title, body, status, session_id, sort, created_at, updated_at)`
- `prompts(id, name, body, as_command, sort, created_at, updated_at)`
- `work_log(session_id, started_at, ended_at)`

## テスト
- ユニット: タスクの並べ替えと状態、git の出力の解析(実際の一時リポジトリで)、コミット、プロンプトの変数展開とコマンドファイルの書き出し(名前の安全化、`codedeck/` の外に書かないこと)、スキルの有効化 / 無効化(フォルダの外に出ないこと)、`claude mcp list` の出力の解析、統計の集計
- E2E: タスクから開始してセッションに指示が入る、差分タブとコミット、プロンプトの挿入、統計の表示
