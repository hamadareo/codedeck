# Phase 2 実装計画(UI/UX の作り込み)

利用者の指示(2026-10-10「他にできることからやっていきましょう」、以前の「判断はあなたに任せます」)を承認として扱う。
2つ目の実アカウント(チーム用)での確認は、利用者の都合で後日行う。

## 範囲(§4、§9 Phase 2)
1. **セッション状態の検出と表示**: 作業中 / 入力待ち / 承認待ち / 完了 / エラー / 上限到達(+ 未起動 / 終了 / 外部ターミナル)。色 + アイコン + 文字で表示する
2. **レイアウト**: 左サイドバーを「プロファイル → プロジェクト → セッション」の階層に。右に開閉できるパネル(メモ、差分、タスク、使用量)
3. **分割ペイン**: 左右・上下の分割、サイズ変更、最大化、ドラッグで入れ替え、別ウィンドウへの切り出し。レイアウトを保存して復元する
4. **コマンドパレット**: `Cmd+K`(Windows はターミナル外で `Ctrl+K`、どこでも `Ctrl+Shift+K` / `Ctrl+Shift+P`)。セッション / プロジェクト / プロファイル / 設定 / コマンドへ移動
5. **テーマと設定**: ライト / ダーク / システム追従、UI の文字サイズ、ターミナルのフォントと文字サイズ、言語(日本語 / 英語)
6. **プロファイルの編集**: 色、種別、アイコン、名前を後から変更できる
7. **オンボーディング**: 3ステップの案内を維持し、「初めての人が3分以内にプロファイル追加 → セッション開始」を E2E で計測する
8. **アクセシビリティ**: 主要機能をキーボードで操作できること、両テーマのコントラスト比が WCAG AA 以上であることをユニットテストで確認する

右パネルの「差分」「タスク」「使用量」は、それぞれ Phase 5 / Phase 5 / Phase 3 で中身を作る。Phase 2 では枠と案内だけ置く。「メモ」は Phase 2 で作る(プロジェクトごとに保存し、セッションへ貼り付けられる)。

## 状態の検出の方式
- `claude --settings <file>` で、CodeDeck 用のフックを**その起動だけに追加**する。プロファイルの設定ファイルは書き換えない
  - `UserPromptSubmit` → 作業中、`Stop` → 完了、`StopFailure` → エラー、`Notification`(`permission_prompt` / `elicitation_dialog`)→ 承認待ち、`Notification`(`idle_prompt`)/ `SessionStart` → 入力待ち
- フックは `async: true` で動かし、claude の処理を待たせない。コマンドは、子プロセスの env の `CODEDECK_STATUS_FILE` に**イベント名の1語だけ**を追記する。プロンプトや出力は書かない(§8)
  - Windows は `shell: "powershell"`(Git Bash がなくても動く)。macOS は `sh`
- main がファイルの追記を監視して状態を更新する。承認待ちのときに利用者がキーを入力したら「作業中」に戻す。完了したセッションを表示したら「入力待ち」にする
- フックが届かない場合(古い claude、`disableAllHooks` など)は、従来どおり「実行中」と表示する
- 上限到達の検出(出力のメッセージから)は Phase 3 で行う

検証: `spike/hook-probe.mjs` で、`--settings` で渡したフックが PowerShell と bash の両方で動き、ファイルに追記されることを確認した(Windows、claude 2.1.296)。

## 分割ペインと別ウィンドウ
- レイアウトは木構造(分割ノード + ペイン)。1つのセッションは同時に1つのペインにだけ表示する
- タブをペインへドラッグすると、そのペインに表示する。ペインの見出しをドラッグすると、ペイン同士を入れ替える
- 別ウィンドウ: main がセッションごとに直近の出力を保持し(最大 1MB)、新しいウィンドウの xterm はその内容を再生してから続きを受け取る。出力には通し番号(オフセット)を付け、重複も欠落もしないようにする
- レイアウトと別ウィンドウの一覧は設定に保存し、再起動後に復元する

## データ
- `settings.json`: `theme`、`uiFontSize`、`terminalFontSize`、`terminalFontFamily`、`locale`、`layout`、`rightPanel`、`popouts` を追加
- SQLite v2: `project_notes(project_id PK, body, updated_at)`

## IPC の追加
- invoke: `settings:get|set`、`notes:get|set`、`pty:snapshot`、`window:popout|dock`、`status:list`、`session:seen`
- event: `settings:changed`、`status:changed`、`windows:changed`。`pty:data` に出力のオフセットを付ける

## テスト
- ユニット: 状態の遷移、フック設定の生成(OS ごとのコマンドとクォート)、ファイル監視、レイアウトの木の操作、パレットの絞り込み、テーマのコントラスト、キーの割り当て、メモの保存
- E2E: 偽の claude が `--settings` のフックを実際のシェルで実行し、状態の表示(作業中 → 完了 → 入力待ち、承認待ち)を確認。分割、最大化、パレット、テーマ切り替え、別ウィンドウ、再起動後のレイアウト復元。初回起動からセッション開始までの時間と操作数
