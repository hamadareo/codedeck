# Phase 6 レポート(仕上げ)

- 実施日: 2026-10-10 / 実機: Windows 11(Mac は CI の macOS ランナー)
- 計画: [phase6-plan.md](phase6-plan.md)、判断: [decisions.md](decisions.md)、利用ガイド: [guide.md](guide.md)

## 実装したもの
| 項目 | 内容 |
|---|---|
| スケジュール実行 | 毎日 / 平日 / 毎週 / 一度だけ。プロファイルとプロジェクトを指定し、時刻に新しいセッションで指示を送る。「今すぐ実行」。**CodeDeck が起動している間だけ動く旨を画面に明記**し、トレイ常駐をすすめる。起動していなかった間の予定は、後からまとめて実行せず「実行しなかった」と通知 |
| 常駐 | 「ウィンドウを閉じてもトレイに常駐する」「ログイン時に起動する」(どちらも既定オフ) |
| SSH セッション | 接続先(`user@host`、ポート、鍵ファイルのパス、リモートのフォルダ、リモートの `CLAUDE_CONFIG_DIR`)を保存し、OS の ssh でリモートの claude を起動・再開する。パスワードや鍵の中身は保存しない |
| パフォーマンス | PTY の出力をセッションごとにまとめて送る(8ms)、xterm の GPU 描画(WebGL、使えなければ従来の描画) |
| 配布物 | アイコン、macOS の universal `.dmg` / `.zip`(hardened runtime、entitlements、Secrets があれば署名と公証)、Windows の NSIS インストーラー |
| 自動更新 | electron-updater(GitHub Releases)。起動時と6時間ごとに確認・ダウンロードし、「再起動して更新」で適用。設定でオフにできる |
| リリースの自動化 | `v*` タグで、両 OS でインストーラーを作り、インストールしてから E2E を実行し、GitHub Release(下書き)に添付 |
| ドキュメント | README の整理、利用ガイド、各 Phase のレポート |

## 利用者の環境で残っていること
- **自動更新**: リポジトリが非公開のため、アプリから GitHub Releases を確認できない(画面には「公開されているリリースがありません」と表示)。自動更新を使うには、リリースを公開する場所(公開リポジトリなど)が必要
- **macOS の署名と公証**: Apple Developer のアカウントがない間は署名なしの dmg になる(開き方は README に記載)
- **実際の Discord**: Bot をサーバー「CodeDeck」に招待し、トークンを入力
