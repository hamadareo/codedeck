# Phase 1 レポート(MVP)

- 実施日: 2026-10-10 / 実機: Windows 11(Mac 実機なし)
- 計画: [phase1-plan.md](phase1-plan.md)、判断: [decisions.md](decisions.md)

## 実装したもの
- Electron + TypeScript + React + Vite(electron-vite)+ Tailwind の雛形。lint・整形・型チェック
- プロファイルの追加・削除・一覧。種別ごとの色(個人=青、チーム=緑)、専用の設定ディレクトリの自動作成、`claude auth status` によるログイン状態の表示(作成直後はログイン用のセッションを開き、/login の完了を自動で検出する)
- プロジェクトの登録と、既定のプロファイルのピン留め(サイドバーからいつでも変更できる)
- セッション: プロファイルを指定して起動、タブ表示、全タブとペインにプロファイルの色とバッジ、ピンと違うプロファイルで始めるときの確認ダイアログ
- セッションの保存と復元(再起動後にタブを戻し、会話があれば `--resume`)。閉じたタブは履歴から開き直せる
- 外部ターミナルで開く(Windows Terminal / PowerShell、Terminal.app / iTerm2)。外部で実行中は、その旨と制限を画面に表示する
- 初回の案内(3ステップ)、`claude` と Git for Windows がないときの案内、i18n の土台(日本語が既定、英語あり)

## 完了条件の確認
> MacとWindowsの両方で、個人用とチーム用の2セッションを、切り替え操作なしで、別タブで同時に使える。再起動後も復元される。埋め込みターミナルで、通常のターミナルと同じようにClaude Codeの機能(スラッシュコマンド、Shift+Tab、/resume、日本語入力)が使える。

| 項目 | Windows | Mac |
|---|---|---|
| 2つのプロファイルのセッションが、別タブで同時に、別々の `CLAUDE_CONFIG_DIR` で動く(切り替え操作なし) | ✅ E2E(偽の claude。開発版とパッケージ版の両方) | ⏳ CI で同じ E2E を実行する設定にした(未実行) |
| ピン留めしたプロジェクトでは自動でそのプロファイル、違うものを選ぶと確認 | ✅ E2E | ✅ CI |
| 再起動後に復元(使った会話は `--resume`、未使用は同じ ID で新規) | ✅ E2E | ✅ CI |
| 本物の claude がアプリ内で描画される(24bit カラー)。新しいプロファイルは未ログインとして検出される | ✅ `REAL_CLAUDE=1` の E2E | ⏳ |
| スラッシュコマンド、Shift+Tab、/resume の候補、日本語の入力と表示、リサイズ | ✅ Phase 0 のプローブ(同じ xterm.js + node-pty の構成) | ⏳ |
| **2つの実アカウントでのログインと同時利用** | 🔶 1つ目(個人)はアプリ内の /login で「ログイン済み」を確認(`claude auth status` で検証)。2つ目は未確認 | ⏳ |
| IME での変換、画像の貼り付け、外部ターミナルで開く | ⏳ 手で確認が必要 | ⏳ |

**結論:** Windows では、自動テストで確かめられる範囲は完了条件を満たしている。実アカウントでの確認と Mac での確認が残っているため、**Phase 1 は「Windows で条件付き完了」**とし、Phase 2 に進む前にこの2点を確認したい。

## テスト
- ユニット(Vitest): 42件。env の整理(プロファイル取り違えの回帰テストを含む)、起動引数、キーの扱い、ピン留めの規則、外部ターミナルのクォート、DB、復元の判断、i18n
- E2E(Playwright + 偽の claude): 主要フロー1本(2プロファイル → ピン留め → 確認ダイアログ → 4セッション同時実行 → 再起動して復元)。パスにスペースと日本語を含む一時ディレクトリで実行
- E2E(本物の claude、任意): 新しいプロファイルで claude の初回画面が描画され、「未ログイン」になる

## 途中で見つけて直したバグ
- 新しいセッションを作った直後、一覧の再取得が終わる前にアクティブなタブが前のタブに戻る
- ダイアログが閉じるときにフォーカスを元のボタンへ戻すため、開いたばかりのターミナルに入力できない(タイミングによって起きる)
- 日本語の UI フォントで、パスの `\` が `¥` に見える
- Electron 44 ではクリップボード API が非同期になっていた

## 手で確認してほしいこと(`npm run dev`)
1. 「プロファイルを追加」で個人用とチーム用を作り、それぞれのタブで `/login` する → サイドバーが「接続済み」とメールアドレスになり、2つが別のアカウントであること
2. プロジェクトを追加してチーム用をピン留めし、セッションを開始 → チーム用で起動すること
3. 日本語 IME での入力、`Shift+Tab`、`/resume`、画像の貼り付け(Windows は Ctrl+V または Alt+V)
4. 「外部ターミナルで開く」→ Windows Terminal で同じ会話が再開されること
5. アプリを再起動 → タブが戻り、会話が再開されること
