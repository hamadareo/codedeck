# CodeDeck 利用ガイド

## 1. はじめに(3ステップ)
1. **プロファイルを追加**: 左の「プロファイル」の「+」。名前と種類(個人 / チーム / その他)を選んで「作成」。開いたタブで claude の案内に従い `/login` します。プロファイルごとに別のアカウントでログインできます
2. **プロジェクトを追加**: 左の「プロジェクト」の「+」でフォルダを選び、既定のプロファイルを「ピン留め」します
3. **セッションを開始**: プロジェクトの「+」(またはタブの「+」、⌘T / Ctrl+Shift+T)。ピン留めしたアカウントで claude が起動します

ログイン情報はプロファイルごとのフォルダ(`~/.codedeck/profiles/<名前>`)に Claude Code が保存し、再起動後も残ります。

## 2. 画面
- **左**: プロファイル → プロジェクト → セッションの階層。各プロファイルの使用量(5時間 / 7日)
- **上**: タブ。色と名前のバッジがプロファイル、右端が状態
- **中央**: ペイン。見出しのボタンで分割(◫ ⊟)、最大化、別ウィンドウ(⧉)、外部ターミナル(↗)。見出しのドラッグで入れ替え、タブをドラッグして表示
- **右パネル**(▥): メモ、差分(Git)、タスク、使用量
- **ツールバー**: ⌕ コマンドパレット、▥ 右パネル、❝ プロンプト、⧉ スキル / MCP、▤ 統計、⏰ スケジュール、⚙ 設定

### 状態の見方
| 表示 | 意味 |
|---|---|
| ◐ 作業中 | claude が作業している |
| ⌨ 入力待ち | 指示を待っている |
| ⚠ 承認待ち | ツールの実行の許可を求めている |
| ✓ 完了 | 作業が終わった(まだ見ていない) |
| ✕ エラー | 失敗した |
| ⏸ 上限到達 | 使用量の上限に達した(リセット時刻をサイドバーに表示) |
| ▶ 実行中 | 状態が分からない(SSH のセッションなど) |

## 3. よく使う機能
- **コマンドパレット**(⌘K / Ctrl+Shift+K): セッションへの移動、新規セッション、プロンプト、テーマ、設定など
- **タスク**: 右パネル「タスク」に追加 →「セッションで開始」で、タスクを最初の指示にしてセッションを開きます
- **Git**: 右パネル「差分」で変更を確認。「Claude Code に考えてもらう」でコミットメッセージを提案してもらい、確認してからコミット
- **プロンプト**(❝): よく使う指示を保存。`{{名前}}` で変数。パレットの「プロンプト: …」で貼り付け。「Claude Code のコマンドにする」で claude の中の `/名前` としても使えます
- **スケジュール**(⏰): 毎日 / 平日 / 毎週 / 一度だけ、時刻に指示を自動で実行。**CodeDeck が起動している間だけ**動きます。⚙ 設定 →「ウィンドウを閉じてもトレイに常駐する」をオンにしてください
- **SSH**: 新しいセッションで「実行する場所」に接続先を選ぶと、リモートで claude を動かします(パスワードはターミナルで入力)
- **使用量**: 右パネル「使用量」で上限としきい値を設定。上限を超えそうになると通知します(推定値。公式の上限は公開されていません)

## 4. Discord(スマホから)
⚙ 設定 →「Discord 連携の設定…」の手順で、自分のサーバーに自分の Bot を招待し、トークンと ID を入力します。

- `/sessions` 一覧、`/send` 指示、`/status` 画面、`/usage` 使用量(設定で `/new`、`/stop`)
- 承認待ちになるとスレッドに「許可 / 拒否」ボタン。長い作業が終わるとメンション
- 許可したユーザー以外は無視されます。危険な操作は追加の確認が必要です

## 5. 設定
テーマ、文字サイズ、ターミナルのフォント、言語、外部ターミナル、通知(種類ごと)、トレイ常駐、ログイン時に起動、自動更新。

## 6. 困ったとき
| 症状 | 対処 |
|---|---|
| 「claude コマンドが見つかりません」 | Claude Code をインストールし、PATH を通してから CodeDeck を起動し直す |
| プロファイルが「未ログイン」 | そのプロファイルのセッションで `/login` |
| 状態が「実行中」のまま | 古い Claude Code ではフックが届きません。`claude update` で更新 |
| Windows で Bash ツールが使えない | Git for Windows をインストール |
| 更新の確認で「公開されているリリースがありません」 | リポジトリが非公開の場合、自動更新は使えません(手動で新しいインストーラーを入れてください) |
| macOS で「壊れているため開けません」 | `xattr -cr /Applications/CodeDeck.app` を実行してから開く |
