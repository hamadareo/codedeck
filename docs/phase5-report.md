# Phase 5 レポート(管理機能)

- 実施日: 2026-10-10 / 実機: Windows 11(Mac は CI)
- 計画: [phase5-plan.md](phase5-plan.md)、判断: [decisions.md](decisions.md)

§9 の順番(タスクバックログ → Git / 差分 / コミットメッセージ → プロンプトライブラリ → スキル / MCP 管理 → 統計)どおりに追加した。

## 実装したもの
| 機能 | 場所 | 内容 |
|---|---|---|
| タスクバックログ | 右パネル「タスク」 | プロジェクトごとのタスク(未着手 / 進行中 / 完了)。追加・編集・削除・並べ替え。「セッションで開始」で、ピン留めのプロファイル(変更可)の新しいセッションを開き、タスクを最初の指示として送る |
| Git 連携 | 右パネル「差分」、ペインの見出し | ブランチ(ペインの見出しにも表示)、変更ファイルと追加/削除行数、ファイルごとの色付き差分、確認してからコミット |
| AI コミットメッセージ | 右パネル「差分」 | 「Claude Code に考えてもらう」で、表示中のセッションに提案を依頼する(コミットはさせない) |
| プロンプトライブラリ | ツールバーの ❝、コマンドパレット | 保存・編集・削除、変数(`{{名前}}` / `{{名前:既定値}}`、組み込みの `{{project}}` `{{cwd}}` `{{branch}}` `{{profile}}`)、パレットから変数を入れてセッションに貼り付け(送信しない)、JSON のエクスポート / インポート |
| `/` で呼び出す | claude の中 | 「Claude Code のコマンドにする」を選んだプロンプトを、各プロファイルの `commands/codedeck/` に書き出す。claude の中で `/名前 引数` として使える |
| スキル / MCP 管理 | ツールバーの ⧉ | プロファイルごとに MCP サーバー(`claude mcp list`)とスキルを一覧。スキルはチェックで有効 / 無効(フォルダの移動、元に戻せる)。MCP の変更は「/mcp を開く」で Claude Code 自身の画面に任せる |
| 統計 | ツールバーの ▤ | 7日 / 30日の使用量・セッション数・作業時間の合計、日ごとのグラフ、プロジェクト別・プロファイル別の表 |

## 確認
| 項目 | Windows | Mac |
|---|---|---|
| タスクの追加 → 「セッションで開始」→ ピン留めのプロファイルでセッションが開き、タスクの内容が送られる → 進行中 | ✅ E2E + ユニット(本物のセッションと偽の claude) | CI |
| 実際の Git リポジトリで、ブランチ・変更ファイル・差分(未追跡のファイルも)・コミット | ✅ E2E + ユニット | CI |
| コミットメッセージの依頼が表示中のセッションに入る | ✅ E2E | CI |
| プロンプトの変数展開、パレットからの貼り付け、コマンドファイルの書き出し(`commands/codedeck/` の外に書かない、利用者のファイルを消さない) | ✅ E2E + ユニット | CI |
| MCP の一覧(`claude mcp list` の解析)、スキルの有効化 / 無効化(フォルダの外に出ない) | ✅ E2E + ユニット | CI |
| 統計の集計(期間の切り取り、プロジェクト外の会話の扱い) | ✅ E2E + ユニット | CI |
| 本物の claude での `/review` などのカスタムコマンド | ⏳ 手で確認してほしい | ⏳ |

## 手で確認してほしいこと(`npm run dev`)
1. 右パネル(▥)→「タスク」でタスクを追加し、「セッションで開始」
2. 右パネル →「差分」で、Git の変更を見る。「Claude Code に考えてもらう」→ 返答をコミット欄に貼ってコミット
3. ❝ でプロンプトを作り、「Claude Code のコマンドにする」をオン → 新しく開いたセッションの claude で `/` を押して候補に出ること
4. ⧉ で、プロファイルの MCP サーバーとスキルの一覧
5. ▤ で統計
